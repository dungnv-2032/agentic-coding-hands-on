# RFP: SunFit 会員体験デジタル化プロジェクト（提案依頼書）

- 発行: 株式会社サンフィットネス 経営企画部
- 発行日: 2026-05-15 / 提案期限: 2026-06-12

## 1. 会社概要
首都圏でフィットネスクラブ「SunFit」24店舗を運営。会員数 約48,000名。

## 2. 背景・課題
- 入会手続きが**店頭のみ**（紙申込書 → 本部で手入力）。機会損失が大きい
- 会員向けアプリがなく、レッスン予約は**電話・店頭のみ**
- 12ヶ月継続率 55%。「成果が見えない」「予約が面倒」が退会理由の上位
- 会員の年齢層が広がり（20代学生〜60代シニア）、既存Webサイトが誰向けか不明瞭
- 競合はアプリ予約・オンラインレッスンを標準装備

## 3. プロジェクト目的
1. 体験予約〜入会をWebで完結し、新規入会を増やす
2. 会員アプリで「予約・入館・記録」を一本化し、継続率を高める
3. オンラインレッスンで店舗外の利用機会を作る

## 4. スコープ
- **公式Webサイト リニューアル**（集客・体験予約・入会申込・決済）
- **会員アプリ 新規開発**（iOS / Android）
- 既存会員システム（基幹）とのAPI連携、既存会員データ移行

## 5. 必須要件
| # | 要件 |
|---|---|
| R1 | 料金プランの比較・店舗検索（エリア/設備） |
| R2 | 無料体験のWeb予約 |
| R3 | 入会申込・クレジット決済のWeb完結 |
| R4 | アプリでのレッスン予約・キャンセル |
| R5 | デジタル会員証（QR）による入館チェックイン |
| R6 | 体重・体組成・運動の記録と推移表示 |
| R7 | ライブ配信・ビデオのオンラインレッスン |
| R8 | プラン変更・支払い履歴照会 |
| R9 | プッシュ通知（予約リマインド・お知らせ） |
| R10 | 友だち紹介キャンペーン機能 |

## 6. 非機能要件
- 個人情報保護: Pマーク運用準拠、決済はPCI DSS準拠の外部決済代行を利用
- 可用性: 稼働率 99.5%以上（予約ピーク: 平日 18-21時）
- 性能: 主要画面 3秒以内表示（4G回線）
- アクセシビリティ: シニア会員を考慮し WCAG 2.1 AA 相当を努力目標

## 7. スケジュール・予算
- 2026-10: 第1弾リリース（Web + アプリ基本機能）
- 2027-01: 第2弾（オンラインレッスン・レポート）
- 予算上限: 非公開（提案内で段階リリース案を提示のこと）

## 8. 提案評価基準
体験設計の具体性 / 段階リリースの現実性 / 保守運用体制 / 費用
