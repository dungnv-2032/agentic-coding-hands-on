# 提案資料サマリ: SunFit 会員体験デジタル化（Sun* 提案）

- 提案日: 2026-06-10 / 提案: Sun Asterisk

## 提案コンセプト
**「入会までをWebで、続けることをアプリで」**
- Webサイト = 見込み客の意思決定装置（比較 → 体験 → 入会をノンストップに）
- 会員アプリ = 継続装置（予約・入館・記録を1タップ圏内に置き、成果を見える化）

## 体験設計の柱
1. **迷わせない入会導線**: プラン比較 → 店舗選択 → 体験予約 → 入会・決済を一直線に。入会完了画面からアプリDLへ直結
2. **「今日行ける」が最初に見えるホーム**: 次の予約・今日のレッスン・継続日数をアプリ起点に
3. **成果の見える化**: からだの記録＋月次レポートで「続いている実感」を作り退会を抑止
4. **幅広い年齢層への配慮**: 1画面1目的・大きめ文字・専門用語を避けたラベル

## 段階リリース計画
| フェーズ | 時期 | 内容 |
|---|---|---|
| Phase 1 (MVP) | 2026-10 | Webサイト全面刷新（比較/店舗/体験予約/入会決済）+ アプリ基本機能（予約/会員証/記録） |
| Phase 2 | 2027-01 | オンラインレッスン（ライブ/ビデオ）・月次レポート・プラン変更 |
| Phase 3 | 2027-04 | 友だち紹介・AIアドバイス・混雑状況表示 |

## KPI（提案）
- Web経由入会: 全入会の 60%
- 体験→入会 転換率: 35% → 50%
- 12ヶ月継続率: 55% → 70%
- レッスン予約のアプリ化率: 90%

## 技術方針（概要）
- Web: Next.js（レスポンシブ）/ アプリ: Flutter（iOS・Android同時）
- 決済: PCI DSS準拠の決済代行（カード情報非保持）
- 基幹会員システムとはAPI Gateway経由で連携、段階移行
